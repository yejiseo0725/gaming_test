# 잠자리 잡기 이벤트 게임

MTS 이벤트 페이지의 게임형 인터랙션을 HTML, CSS, JavaScript로 구현한 과제입니다.

- 이미지 에셋 없이 기본 도형으로 동작 위주로 구현했습니다.

## 게임 방법

1. "게임 시작하기"를 누르고, 안내 화면을 터치하면 게임이 시작됩니다.
2. 위아래로 움직이는 잠자리(원)가 점선 사이 성공 영역에 들어왔을 때 "캐치!"를 누릅니다.
3. 기회 5번 안에 목표 마리 수를 잡으면 성공입니다. 제한 시간은 15초입니다.

## 구현 내용

- 화면 흐름: 인트로 → 튜토리얼 → 게임 → 결과
- 기회별 성공·실패 표시, 목표 달성 또는 기회·시간 소진 시 종료
- 남은 기회로 목표를 채울 수 없으면 바로 실패 처리
- 판정할 때마다 이동 속도 증가

## 구현 방식

- 상태 관리: `phase`(ready / playing / judging / end) 값 하나로 흐름을 제어합니다. 판정 중에는 이동이 멈추고 버튼 입력을 무시해 연타를 막습니다.
- 이동: `requestAnimationFrame`으로 매 프레임 위치를 계산하고 `transform`으로 적용합니다. 프레임 간 경과 시간(dt)을 곱해 기기 주사율과 관계없이 같은 속도로 움직입니다.
- 판정: 버튼을 누른 순간 `getBoundingClientRect()`로 잠자리 중심이 성공 영역 안에 있는지 비교합니다.
- 타이머: 같은 반복 함수 안에서 경과 시간을 차감해, 탭이 비활성화되면 함께 멈춥니다.
- 설정 분리: 목표 마리 수, 기회 수, 제한 시간, 속도는 `game.js` 상단 `CONFIG`에서 조정합니다.
- 모바일·접근성: 모든 조작 요소는 `button` 태그를 사용했고, `touch-action: manipulation`으로 더블탭 확대를 막았습니다. 판정 결과는 `aria-live`로 스크린리더에 전달됩니다.
